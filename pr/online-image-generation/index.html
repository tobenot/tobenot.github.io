在线图片生成

一个接入自己模型服务的浏览器图片工具。可以根据文字生成图片，上传参考图进行修改，也可以批量处理提示词和整理生成结果。

打开直接用 了解功能与使用条件

这个工具怎么用

在线图片生成是一个面向 OpenAI 兼容图片接口的网页工具。使用时填写模型服务地址、API Key 和模型名称，再输入想要的画面描述。图片由所连接的模型生成，网站负责提交任务和展示结果。

除了文字生图，还可以上传参考图片，在支持编辑的模型上修改图片，并使用蒙版指定要编辑的区域。批量模式可以一次提交多条提示词，使用相同的参考图和设置，适合尝试一组角色、物品或场景方案。具体支持的尺寸、参数和编辑方式取决于模型服务。

生成结果可以在任务列表和图库中查看，支持选择多张图片并打包下载。图库保存在浏览器本地，重要图片需要另行下载备份。浏览器存储空间有限，清除站点数据或自动清理较早缓存都可能让本地图片不再保留。

工具本身免费，不提供无限生图额度。请求从浏览器发往你配置的 API 服务，提示词和上传的参考图会交给该服务处理。服务商需要允许浏览器跨域访问，模型调用费用与内容使用条件按服务商规则执行。

图片生成与整理

文字生成图片

输入画面描述，选择模型、数量和尺寸后提交任务。可以用于尝试插画、头像或游戏美术方案。

参考图与局部编辑

上传图片后进入编辑流程，在兼容模型上使用参考图和蒙版。并非所有服务都支持相同的编辑参数。

批量生成

按行输入提示词，或粘贴 CSV 内容，使用共享设置运行一组任务，再将结果打包下载。

图片识别

使用支持图片输入的视觉模型描述图片或提取文字。该功能使用单独配置的视觉模型，需要服务支持相应接口。

素材重命名

让视觉模型根据图片内容提出文件名，下载用于 Windows 的重命名和撤销脚本。执行前应检查命名结果。

任务与图库

查看任务状态和生成结果，设置并发数量，并从图库中选择图片下载。网页中的费用估计仅供参考。
