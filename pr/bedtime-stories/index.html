这个网站用来做什么

与AI的睡前故事 2 以 AI 对话为主要功能。你可以用它讨论问题、整理写作思路，或者继续一段已经聊了很久的话题。网站提供对话界面和记录管理，回答由你选择的模型服务生成。

如果想换一种问法，可以修改消息后重新生成回答。也可以从已有对话分出另一条分支，比较不同的讨论方向。聊天内容支持 Markdown 和代码显示，多个会话可以分别保存。

聊天记录默认保存在当前浏览器中，可以归档、导出、重新导入或清理。换设备前需要自己导出备份，清除浏览器数据也可能影响本地记录。本地保存指记录的存放位置，发送消息时，相关对话内容仍会交给所选模型服务处理。

网站无需注册站内账号，工具本身免费。开始使用前，需要选择模型服务并完成相应配置，通常需要自己的 API Key，模型调用费用由服务商收取。绘图功能已经迁移到独立绘图站，旧绘图会话仍可查看。

对话与记录管理

修改与分叉对话

可以编辑消息、重新生成回答，也可以从某条消息分出新的讨论分支，保留原来的对话。

选择模型服务

可以使用内置服务预设，也可以填写自定义接口和模型。不同模型支持的参数与功能可能不同。

本地记录与备份

支持会话归档、导出和导入，导出存档时可以选择加密。界面的屏幕锁只隐藏内容，不等于加密记录。

提示词缓存设置

在兼容的模型和接口上，可以选择缓存时长或设置消息缓存断点。是否生效及如何计费取决于模型服务。

文字冒险

游戏模式可以使用机制包，让 AI 按设定主持文字冒险，并配合掷骰、状态记录等功能。

独立绘图站

新建绘图任务请使用 image.tobenot.top。该站使用单独的图片生成接口，需要配置支持生图的模型服务。
